Learn touch typing by playing: a story campaign, a real curriculum and a coach for every key.

Frequently asked

Do I need a hardware keyboard?

It is designed for one — touch typing is learned on a physical keyboard. On iPad the game is also fully playable by touch using the on-screen console keyboard, and every screen has on-screen controls.

Which keyboard layout does the course teach?

The English course uses the US QWERTY layout. The game reads the physical position of each key, so it works even if another input language (for example Russian) is active on your device.

How are stars earned?

One star for completing a mission, two for good accuracy, three for high accuracy at the mission's speed goal. Thresholds depend on the pilot's difficulty level: Relaxed, Standard or Ace.

How do profiles work?

Title screen → Pilots. Up to 8 pilots per device, each with their own progress, statistics, streak, settings and difficulty. Press N for a new pilot, R to rename, ⌫ to delete (confirmed with Y).

What do the keyboard shortcuts do?

In menus: arrows and ⏎. In a mission: type to shoot, ⏎ fires Overdrive when charged, ⌫ releases the current target, esc pauses. On iPad without a keyboard, use the pause button in the top-right corner.

How do I start over?

Settings → Reset progress, or delete the pilot in the Pilots screen and create a new one.
